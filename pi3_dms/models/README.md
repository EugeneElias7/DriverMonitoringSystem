# Model

This deployment uses exactly one model:

```text
face_landmarker.task
```

SHA-256:

```text
64184e229b263107bc2b804c6625db1341ff2bb731874b0bcc2fe6544e0bc9ff
```

The file is the MediaPipe Face Landmarker task model. The app loads it locally;
there is no download at startup.

The model and MediaPipe runtime have their own licence and model-card terms.
Review those terms before redistributing this folder or using it commercially.
The model is used here for research/demo purposes only and is not validated for
safety-critical driver monitoring.
